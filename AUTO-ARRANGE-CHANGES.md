# FINDAT horizontal desktop arrangement

- Newly dropped or uploaded documents use the next free grid position.
- Documents start below the FINDAT system shortcuts and fill from left to right.
- When a row is full, documents continue on the next neatly spaced row.
- Existing saved document positions are placed first and never shift when a new file is added.
- Documents and system shortcuts can be dragged freely and retain their exact saved positions.
- Collision protection prevents a dragged or newly added icon from covering another icon.
- Supabase-only storage and green saved ticks remain unchanged.

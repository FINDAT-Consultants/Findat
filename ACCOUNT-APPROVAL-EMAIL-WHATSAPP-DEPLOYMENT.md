# FINDAT account approval, email and WhatsApp activation

This update preserves the existing public-registration approval workflow and adds:

- an in-system notification for every active Administrator when a new Client registers;
- a **Review account** action that opens **User Accounts**;
- email confirmation and profile activation when the Administrator approves the account;
- an activation email through Resend;
- an activation WhatsApp template message through Meta WhatsApp Cloud API;
- a secure password setup/reset link generated by Supabase Auth.

## Security rule

FINDAT does not store or send a readable password. Supabase stores password hashes and cannot return the original password after registration. The activation messages therefore show the username, tell the user to use the password created during registration, and include a secure password setup/reset link.

## 1. Run the SQL

In **Supabase Dashboard → SQL Editor**, run:

```text
FINDAT-ACCOUNT-ACTIVATION-NOTIFICATIONS-UPGRADE.sql
```

This can be run after the earlier Auth/RBAC and collaboration notification migrations. It creates Administrator registration notifications and keeps pending account approvals from being cleared accidentally.

## 2. Deploy the updated Edge Function

Deploy:

```text
supabase/functions/findat-admin-users/index.ts
```

Using the CLI:

```bash
supabase functions deploy findat-admin-users
```

Keep JWT verification enabled for `findat-admin-users`.

## 3. Configure activation email

Use a verified Resend domain and add these Supabase Edge Function secrets:

```text
RESEND_API_KEY=re_xxxxxxxxx
FINDAT_ACTIVATION_EMAIL_FROM=FINDAT <accounts@your-verified-domain.example>
FINDAT_SITE_URL=https://your-domain.example/
FINDAT_PASSWORD_SETUP_REDIRECT_URL=https://your-domain.example/
```

The activation email is sent by the Edge Function and does not use Supabase's limited built-in Auth email service.

## 4. Configure WhatsApp Cloud API

Create and approve a Utility template in WhatsApp Manager with the name:

```text
findat_account_activated
```

Suggested body:

```text
Hello {{1}}, your FINDAT account has been activated.
Username: {{2}}
Use the password you created during registration. Set or reset it securely here: {{3}}
```

Add these Supabase Edge Function secrets:

```text
WHATSAPP_ACCESS_TOKEN=your_permanent_or_system_user_token
WHATSAPP_PHONE_NUMBER_ID=your_phone_number_id
WHATSAPP_ACTIVATION_TEMPLATE_NAME=findat_account_activated
WHATSAPP_TEMPLATE_LANGUAGE=en_US
WHATSAPP_GRAPH_API_VERSION=v21.0
WHATSAPP_DEFAULT_COUNTRY_CODE=260
```

`WHATSAPP_DEFAULT_COUNTRY_CODE=260` converts a Zambian number such as `097...` to the international digits expected by WhatsApp. Users may also register with a full number such as `+26097...`.

Use a current Meta Graph API version supported by your WhatsApp application. The version is configurable so it can be updated without changing the code.

## 5. Administrator workflow

1. A new Client completes registration.
2. The profile remains **Pending / inactive**.
3. Every active Administrator receives a real-time notification.
4. The Administrator opens the bell and selects **Review account**.
5. **User Accounts** opens with the pending account.
6. The Administrator selects **Approve / Activate** or **Confirm email**.
7. Supabase confirms the Auth email and activates the profile.
8. FINDAT sends the activation email and WhatsApp message.
9. The Administrator sees the delivery result for both channels.

## Delivery behaviour

Activation is recorded even if an external provider is temporarily unavailable. The Administrator receives an immediate result showing `sent`, `skipped`, or `failed` for email and WhatsApp. After correcting provider settings, the Administrator can suspend and reactivate the account to resend the activation messages.

Never place Resend, WhatsApp, Supabase secret/service-role, or OpenAI keys in GitHub, `index.html`, `findat-auth-config.js`, or browser JavaScript.

# Superseded public-registration approval guide

The Administrator-confirmation workflow has been replaced by automatic Client activation.

Use `AUTOMATIC-CLIENT-REGISTRATION-DEPLOYMENT.md` and run `FINDAT-AUTOMATIC-CLIENT-REGISTRATION-UPGRADE.sql`.

The compatibility file `FINDAT-PUBLIC-REGISTRATION-APPROVAL-UPGRADE.sql` now applies the same automatic-registration upgrade, so it will not restore the old pending-approval behavior.
